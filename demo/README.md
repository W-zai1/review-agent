# 3 分钟演示（无真实文档版）

这两份文档是**合成样例**，不是真实合同/报告。它们只用来演示链路，不用来证明准确率。
真实效果必须以真实文档 + 人工标注为准；当前没有真实文档，所以这里只做“能力演示”，
不做“质量声明”。

## 演示脚本（约 3 分钟）

### 0:00–1:20 合同：从“可疑”到“改哪一句、改成什么、不改会怎样”

```bash
py -3 review.py demo/contract_labor.txt --no-llm --no-research
```

打开 `outputs/R-<id>.md`，只讲第一屏「整改单」：

1. 试用期 12 个月 → 整句改为“最长不得超过六个月”，并说明“超过部分无效、员工可主张补差”。
2. 试用期工资 60% → 整句改为“不得低于约定工资的百分之八十”。
3. 竞业限制 3 年 → 整句改为“不得超过二年，超过部分无效”。
4. 缺终止条款 → 给出可直接粘贴的条款模板，位置写明“签署页之前”。
5. 缺争议解决条款 → 给出管辖条款模板，后果写明“异地诉讼、周期和成本上升”。

一句话：**这五条都不需要用户再问“那我该怎么改”。**

### 1:20–2:30 事实：不再写“无出处”，而是给“查到什么、来源在哪”

```bash
py -3 review.py demo/claim_report.txt --no-llm --research
```

打开报告，看两块：

- 「事实核验」：小米 5 亿 → 来源显示 1.69 亿，附新浪财经 / 199IT 两条来源；报告给出
  “1.69 亿台”的整句改写。
- “公司产品渗透率 35%” → 没有可比来源，**不生成问题**，只在核验区写“查过什么、没找到”；
  裁定从 pass 降为 warn：`1 条库外事实未找到可比来源，需人工核验`。
- 豆包 MAU 10 亿 → 内置事实库判为 1 亿量级，整改单给出改写。

一句话：**“没查到”和“是假的”分开说；“单一来源”和“两个来源一致”也分开处理。**

## 演示时不要说的话

- 不要说“能审所有合同”：当前只覆盖 33 条规则 + 少量事实断言，合同结构还没解析。
- 不要说“能判断所有事实真假”：只核验“有名实体 + 指标 + 数值/日期”的硬主张，
  每份文档最多 3 条，公开搜索会限流。
- 不要说“已经过真实评测”：没有真实文档，当前只有 35 个自建微用例 + 23 条标注。
- 不要把“未找到”说成“没问题”；报告里已经明确写了不等于虚假。

## 如果评审追问

- **“这不就是 prompt 吗？”**
  不是：确定性算术/法条/事实库先跑，模型只做语义补充；所有结论必须过 quote 逐字校验，
  严重度由规则库定，模型无权改级。
- **“模型胡说怎么办？”**
  quote 必须逐字命中原文；规则外发现单独标 `OPEN-*`；单一来源反驳只进待确认；
  查不到就不生成 issue。
- **“怎么证明有效？”**
  诚实回答：还没有真实文档评测。下一步是 30 份真实合同 + 双人标注 + 四组配置对比；
  当前只能演示链路，不能声明准确率。
