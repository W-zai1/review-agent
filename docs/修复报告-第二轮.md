## 二、逐项修复

### P0 · V1 非 UTF-8 直接崩溃

`run_one` 直接 `read_text(encoding="utf-8")`。改为 `read_target_text()`：依次尝试
`utf-8 → utf-8-sig → gb18030 → utf-16 → utf-16-le/be`，全部失败才用替换字符解码并**显式告警**。
编码记入 `coverage.source_encoding`，非 UTF-8 时在 limitations 说明。

> 原则：审查工具的底线是「对任意输入都给结论」，不是「只接受 UTF-8」。
> 崩溃等于连"这份文件我没法审"都说不出来。

### P1 · V2 安全关键词无语境，合法安全文档被判 fail

SAFE-001/002 是裸关键词。新增**防御性语境豁免**：同句出现
`检测|监测|防护|防御|演练|加固|审计|排查|应急|治理|对抗|方案|白皮书|合规|渗透测试…`
时不出 blocker，改为决策日志记录「防御性语境，未报」。

### P1 · V3 千分位 / V4 中文数字

- `NUM_RE` 支持 `1,360` / `1,234.5`；
- `TOTAL` 与金额抽取支持中文数字：新增 `cn2num()`（支持 `万/亿` 分组），
  并规定**中文金额必须带万/亿单位**才认——否则「二季度」「三月」会被当金额。
- 日期同样支持中文（`十月十八日`）。

### P1 · V5 类型误判把 COMP-004 静默关闭

`COMP-004` 的启用条件从「类型 ∈ {llm_response, prompt} 或置信 <0.8」改为
**「类型 ≠ code」**。类型猜测只允许增加检查，不允许删减——这条现在有测试锁住。

### P2 · V6 合计窗口污染

`check_sums` 取「合计前最后 k 个同单位金额」时，跳过前面 8 字内出现
`增长|下降|减少|增加|提升|下滑|同比|环比|涨|跌|净增|净减` 的数字——它是变化量，不是分项。

### P2 · V7 年份推断取错

三代实现的教训：① 取全文首个年份 → 多年度文档按错误年份算；② 取最近裸年份 →
被「豆包 2024 年 MAU」这种无关口径带偏。最终规则：

```
内联年份 → 最近的「YYYY 年 M 月」锚点 → 最近的裸年份 → 放弃
```

只有"年+月"才代表具体时点；实在没有就不判（宁可漏，不可用错年份断言星期）。

### P2 · V8「投入 N 个月」不是工期

`DURATION` 去掉 `共|投入|持续` 前缀，只认 `历时|前后|跨度|工期|耗时`。
「团队共投入 6 个月人力」是工作量。

### P2 · V9「研究 N 年」不是工龄

工龄检查前先看自述句：含 `研究|从事|入行|从业|经验|深耕|做这行|干这行|接触` 则跳过。

### P2 · V10 占比分子读主语

先从「…占」前读显式主语（如「**行政**占员工总数的 10%」），在同句找该主体人数；
找不到才回退「最近一个 N 人」。「行政 20 人、生产 160 人，行政占 10%」不再取成 160。

### P2 · V11 口语词无词边界

新增 `CASUAL_EXEMPT`：`哈尔滨|哈佛|哈哈|酒吧|网吧|氧吧|吧台|书吧|哈欠|哈萨克|哈希|哈工大…`
匹配前先剔除，避免地名/场所名误报。

### P2 · V12 零宽字符同时制造误报与漏检

入口处 `strip_invisible()` 剥离 `U+200B/200C/200D/2060/FEFF`，**在所有匹配之前**执行，
剥离数量记入 `coverage.invisible_removed` 并在结论里说明。
不剥离会出现同一字符导致「条款存在却报缺失」+「金额被拆断导致合计漏检」。

### P2 · V13 无引号密钥漏检

`SECRET_RE` 扩展为三种形态：带引号（≥3 字符）、无引号裸值（≥8 字符）、`sk-` 前缀；
键名增加中文 `密钥|口令|密码|凭据`。

### P2 · V14 无括号星期漏检

`DATE_WEEK` 括号改为可选，`11 月 5 日 周五` 与 `11 月 5 日（周五）` 都能识别。

### P2 · V15 code 维度收缩（by-design，但要可见）

保持设计（代码对象只跑安全+风格），但写入 `coverage.uncovered`：
「注释/docstring 中的事实性错误、数值/日期矛盾不在本次检查范围内」。

### P2 · V16 事实审把年份当比对基数

取数时跳过「1900–2100 且紧跟「年」」的数字，取下一个真实指标值。
「2024 年底突破 10 亿」现在得出**10 倍**偏差，而不是 0 倍。

### P2 · V17 SAFE-004 覆盖窄

注入句式扩展：`忽略(以上|所有|之前)`、`绕过…(审查|规则|检查)`、`直接判定为通过`、
`把…(合计|金额|数字)改为`、`隐藏…(问题|矛盾|错误)`。c04 样本现在规则层即可命中，
不再完全依赖 LLM。

### P3 · V18 COMP-004 噪声

两处收窄：① 标题行（`#`/`【`）与**日期/编号类数字**（后接 年/月/日/号/周/届/期/名，
或前接 第/周/月）不再算"裸数据"；② 口径词补充 `占…(总数|员工|营收)|比重|比例|份额`。

### P3 · V19 跨块矛盾

未修复（架构性）。已在 limitations 与 `coverage.uncovered` 继续标注：
分块审查覆盖全文，但相隔很远的句子不会被同一块看到。
