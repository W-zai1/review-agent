# 第三阶段 · 工具能力分类与去重盘点（第一刀）

- 依据：`Review-Agent_系统架构审查与整改建议.md` 问题 5（工具层未迁移）与阶段三（能力层收敛）。
- 基线：`1f512a2`，VERSION 0.9.2，工作区干净；`tools/*.py` 共 46 个。
- 口径：静态 AST 分析（2026-11-08），非人工估计。
- 本轮性质：**只分类、只守门，不改任何运行代码**。删除/合并/迁移另开任务，逐项按铁律 8 的五项检查过。

## 0 结论先行

1. 46 个模块 = **27 个运行期可达** + **19 个纯运维/CLI**；34 个带 `__main__`（可直接当脚本跑）。
2. 「同一能力多份实现」**不成立**：`tools/dup_audit.py` 全仓只报 1 组同名函数，且是**同名不同物**（见 §3-⑤）。真正需要合并的重复为 **0 处**。
3. 有 **3 处待确认重叠**（docx 文本抽取、密钥正则、学习配置默认值）与 **1 处兼容壳**（`integrity.verify_ledger`），本轮只登记、不动刀。
4. 注册表已接 **13 个工具**（`build_capability_registry()` 静态注册 12 个 + `research.web` 运行期条件注册 1 个），覆盖 **15 个模块**；未接的 12 个可达模块按「算法源注入」与「非审查原子能力」两类解释（§4）。
5. 阶段三的真实缺口不是「重复」，而是**边界**：哪些模块是能力层、哪些只是脚本工具，此前没有一份可执行的清单。本文件即该清单。

## 1 口径与判定规则

| 概念 | 定义 |
|---|---|
| 运行期可达 | 从 `review.py` / `server.py` 出发，经 `tools/` 内部 import 传递可达（AST 静态分析）。`间接` 指仅被其他 `tools/` 模块引用，如 `ocr` ← `ingest`。 |
| 注册表 | `review.py:1916 build_capability_registry()` 实际注册的工具名，实现在 `review_agent/capabilities/builtin_tools.py`。 |
| 重复 | 同一算法/规则的第二份实现，且两份都在运行期或都能被外部调用。**分层与组合不算重复**（如 `adapters/model.py` 包装 `llm_client`）。 |
| 处置 | 只允许三种：`保留`（能力/算法，已或可被 v1 复用）、`保留·兼容壳`（有调用方，退出条件见 §5）、`保留·运维`（脚本/CI 用，不进能力层）。 |

**本轮不设「删除」处置**：按铁律 8，任何删除都要先过五项检查；在无动态导入、无插件调用、无脚本/CI 引用、无迁移职责、且有测试替代这五项全部确认前，一律保留。

## 4 未接注册表的 13 个可达模块：为什么暂不接

| 类型 | 模块 | 理由 |
|---|---|---|
| 算法源 / 配置装配 | `agent_spec` `purpose` `scenario` `format_spec` | 被 `build_rule_registry()` 与 Planner 读取，是**输入**而非可调用能力；包成工具会制造无意义的一次性包装。 |
| 模型与外部适配 | `llm_review` `ocr` `llm_client` `research`* | v1 经 `review_agent/adapters/model.py` 与 `runtime/nodes/` 调用；`llm_client` 是基础设施，不是审查动作。*`research` 已通过 `research.web` 接入。 |
| 状态/存储/闭环 | `rules_store` `rule_learning` `remediation` `fact_gap` | `rule_learning` 会写 `state/`/`rules/`，有副作用，不适合作为可重试的工具调用；`rules_store` 是存储层；`remediation`/`fact_gap` 是报告装配阶段。 |
| 纯数据表 | `secret_patterns` | 只有正则常量、没有调用接口；由 `regex_check`/`secret_scan` 按用途取子集，包装成工具没有意义。 |
| 版本常量 | `version` | 被入口层读取的元信息。 |

> 结论：**注册表只收「无副作用、可重试、有明确输入输出」的审查原子能力**。这也是问题 5 里「不硬包装」的落点。

## 6 本轮不做（阶段三后续刀口）

> 第 1 条只约束 2026-11-09 的第一刀（纯盘点）。2026-11-10 第二刀只改了 `regex_check`/`secret_scan` 的正则来源与新增 `secret_patterns`，检测集合未变。

1. 不迁移、不改任何 `tools/*.py` 运行代码；本文件是**只读盘点**。
2. 不删除任何模块（含 19 个运维脚本），铁律 8 的五项检查未逐项走完。
3. 不动 `rule_learning` 的 `auto_ok_dimensions`（`logic`/`style` 自动晋升）：属暂停清单第 3 项「自动规则晋升」，需单独立项。
4. 不动 `tools/` 与 `review_agent/capabilities/` 的依赖方向：现有做法是 `review.py` 注入算法、`builtin_tools.py` 只写壳，已满足「capabilities 不 import tools」。
5. 不改报告 schema、不改公共 API 签名、不碰 `outputs/ logs/ state/ ledger/ targets/ cache/`。
