## 1. 目标与验收（整阶段）

- 入口层不再承载业务逻辑：`review.py` / `server.py` 只做参数转换、调用 Application。
- 路由只处理请求/响应/鉴权/参数转换。
- 报告生成与渲染只有一个权威实现（v1 已在 `application/`；legacy 保持冻结）。
- 错误处理、配置加载各只有一个入口。
- 行为等价：报告 35 键不变、API/CLI 输出不变、`checks`/`tests` 全绿。
