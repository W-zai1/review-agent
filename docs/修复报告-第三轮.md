## 一、这一轮最该记住的教训

第二轮的五条 P1 全是**词表/窗口不完整**被打穿：

| 第二轮修法 | 第三轮绕过方式 |
|---|---|
| 增长词前 8 字窗口 | 把「较上月有所增长」写在数字**后面** |
| 防御语境词表（检测/防护/方案…） | 换成「**拦截**网络入侵」「被防火墙**阻断**」 |
| 工龄豁免词表（研究/从事/深耕…） | 换成「我在这行**摸爬滚打**二十年」 |
| 年份取最近「年+月」锚点 | 用「2024 年 12 月**版本**」当锚点 |
| 百分号只认紧邻 `%` | 换成全角 `％` 或 `45 %` |

**结论不是继续加词，而是换判断方式**：能识别结构的地方就别枚举词。这轮五条 P1 全部改成了结构性判断：

- 增长语境 → **前后对称窗口**（不再只往前看）；
- 年份 → **只认"有效时点锚点"**（版本/修订/口径类不算），全部无效就**不判**；
- 工龄 → 识别**行业/从业语义**（出现「这行/行业/领域」或从业动词族就说明说的不是在职年限）；
- 安全 → 识别**安全运营统计形态**（拦截/阻断/告警/处置/研判/溯源…）；
- 百分号 → 正则 `\s*[%％]`，不再要求紧邻。

## 二、逐项修复

### N1【P1】增长词后置绕过 → 合计误报
`_is_growth()` 原只检查数字前 8 字；改为**前 8 + 后 18** 的对称窗口，并把金额的 `end` 一并传入。
「回款 45 万元（较上月有所增长）」不再被当作分项参与求和。

### N2【P1】全角/带空格百分号绕过
百分比判定从「下一个字符 == `%`」改为 `re.match(r"\s*[%％]")`。`45 ％`、`45 %` 都不再当金额。

### N3【P1】版本类「年+月」被当时点锚点
新增 `_valid_anchors()`：锚点后 12 字内出现 `版本|修订|版次|口径|基准|截至|发布|更新|存档|归档` 即判为**非时点**。
解析顺序变为：内联年份 → **最近有效锚点** → 裸年份（但排除只出现在版本语境里的年份）→ 放弃。

### N4【P1】工龄豁免词表被绕过
不再枚举动词，改为识别语义：句中含**行业/领域词**（这行、行业、领域、本职、本行、专业、技术、市场、销售、研发、财务、管理、业务、岗位、手艺、一线）
或**从业动词族**（研究、从事、入行、从业、深耕、摸爬滚打、闯荡、打拼、投身、扎根…）→ 不判。

### N5【P1】安全运营统计被判 blocker
防御语境词表补齐安全运营高频词：`拦截|阻断|告警|研判|处置|响应|溯源|态势|巡检|值守|封禁|清洗|监控|安全运营|统计|报表`；
同时 SAFE-002 增加倒序形态 `密码破解`（原来只认「破解密码」）。
「共拦截网络入侵 12 起…全部被防火墙阻断」现在 pass。

### N6【P2】短值/纯数字密钥漏检
无引号裸值门槛 8 → **5**；键名补 `pwd|pw`；新增 `SECRET_PLACEHOLDER` 排除 `null/none/true/false/int/str/os.environ…` 这类赋值右值，避免降门槛带来的误报。
`密钥 = 1234567` / `apiKey = abc12` / `DB_PW = "pw12345"` 三条全部命中。

### N7【P2】事实库实体-属性碰撞
`facts.json` 的断言支持 `exclude_ctx`：豆包月活条目排除 `大模型|模型|API|开放平台|接口|调用量|企业版`。
命中排除词时**不比对**，并在决策日志记录「属另一口径，未比对」。
「豆包大模型月活 1000 万」不再被套用 App MAU 口径判 blocker。

### N8【P2】报告 .md 未转义原文
新增 `_md_safe()`：把 `\ ` ` [ ] * _ | < >` 全部转义，并把 `javascript:/data:/vbscript:` 的冒号转义。
`[官方文档](javascript:alert(1))` 渲染后是纯文本，不再是可点击链接。

### N9【P3】COMP-004 残余噪声
新增 `drop_covered_comp004()`（S2 末尾执行）：同一句若已被 `LOGIC-*` / `FACT-*` 报出，
就不再叠一条"数字无来源"的提示。
> 为什么不能在 COMP-004 内部判断：它在 S2 靠前执行，看不到后面才产生的算术/事实异议。

### F1【P2】docx 无解压上限
`extract_docx` 增加 `MAX_DOCX_XML_BYTES = 8MB`：先用 `ZipInfo.file_size` 判断，再 `z.open(...).read(上限)` 限量读取。
与 PDF 的 8MB 解压上限对齐；超限记 warning「已截断读取」。

### F2【P2】ZIP 嵌套上限是死代码
`ingest_file(..., depth=0)` 增加 depth 参数并透传（原来每次递归都取默认 0，`depth > MAX_ZIP_DEPTH` 永远为假）。
**并且嵌套超限改为整包拒绝**（不再"成员跳过 + ok:true"）——否则用户以为整包都审了，实际内容没展开。

### F3【P3】Windows 保留名假成功
`_safe_upload_name()` 增加保留名检查（`con|prn|aux|nul|com1-9|lpt1-9`），命中则前缀下划线改名。
`CON.txt → _CON.txt`，不再出现"接口说成功、磁盘上没文件"。

### F4【P3】JSON body 无上限
`_json_body()` 在读入**之前**检查 `Content-Length > 1MB` → 返回 413；调用点识别 `None` 后直接结束，不再继续解析。
